# Code of Conduct

This project is for practical local-first agent memory work. Contributors are expected to keep discussion technical, respectful, and focused on reproducible evidence.

## Expected Behavior

- Be direct without being hostile.
- Critique code, design, tests, and documentation rather than people.
- Keep issues and pull requests scoped to one problem when possible.
- Do not publish another person's private evidence, transcripts, tokens, or local paths.
- Respect maintainers' decisions on project scope and security boundaries.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Posting secrets, private evidence, or raw private transcripts.
- Repeated off-topic comments after maintainers ask to stop.
- Attempts to bypass local-first privacy boundaries or security review.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject pull requests; or block contributors when needed to keep the project safe and maintainable.

Security-sensitive reports should follow [SECURITY.md](./SECURITY.md), not public issues.
