# LSP And Static Analysis Adapters

## Purpose

Use LSP/static tools for current repo structure while preserving harness semantic lineage.

## Adapter Inputs

- definitions
- references
- imports
- call hierarchy
- diagnostics
- symbol tables
- type information

## Harness Additions

The harness adds:

- work causality
- version lineage
- relation occurrences
- prior validation
- task-specific cards

## Rule

LSP output is structural evidence. It does not explain why code changed unless connected to work-window and reasoning evidence.
