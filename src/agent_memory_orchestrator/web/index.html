Connectors

Slack mention answers without a public webhook

AMO runs Slack in local Socket Mode. The bot captures relevant channel messages as raw evidence, and when the bot is tagged it queries GraphRAG and replies in the same Slack thread.

Slack flow

Tagged-channel answer path

The answer mode is intentionally narrow: no response to normal channel chatter, only tagged bot mentions.

1. Mention<@AMO> asks a memory question in a channel or thread.
2. CaptureThe message is appended to local raw evidence with source_app=slack.
3. RetrieveAMO runs GraphRAG over committed central memory and selected historical context.
4. ReplyThe bot posts a compact answer with node/evidence/commit refs.

Operator commands

Run locally

Slack tokens stay local. The web UI only displays status; the connector process runs from the terminal.

amo-cli slack setup-wizard
amo-cli slack run --reply-mode answer
